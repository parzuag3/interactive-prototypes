The name of the game is Tic Tac Toe, or Noughts and Crosses, with this simulation program made by Pedro Arzuaga III and James Ferchak. This game is a turn-based two-player game, in which 
both players compete in forming a row, a column, or a diagonal line with three of their chosen symbol in a three-by-three grid board. Any symbol can be used in a general game, but this 
simulation program has set Player 1's choice to X's, and Player 2's to O's. If both players fail to create a line before all of the boxes in the board are filled in, the conclusion is a 
Draw.
